JellyBean

Un clavier WiFi via un module externe

Rejoindre le Discord

Pour utiliser L'application jellyBean, vous devez posséder un plug-in JellyBean

Comment le configurer ?

1. Standalone
Ne nécessite pas l'utilisation d'un réseau WiFi interne

Étapes :

  1. Branchez le plug-in JellyBean sur votre ordinateur
  2. Sur votre téléphone, connectez vous au réseau WiFi JellyBean_Hotspot

    3. SSID -> JellyBean_Hotspot

    WPA -> jellybean

  3. Ouvrez l'application JellyBean et appuyez sur le bouton 'Standalone'
  4. La configuration est terminée
2. Serveur
Nécessite l'utilisation d'un réseau WiFi interne

Étapes :

  1. Branchez le plug-in JellyBean sur votre ordinateur
  2. Sur votre téléphone, connectez vous au réseau WiFi JellyBean_Hotspot

    3. SSID -> JellyBean_Hotspot

    WPA -> jellybean

  3. Ouvrez l'application JellyBean, appuyez sur le bouton 'Server' et renseignez les identifiants de votre réseau WiFi
  4. Attendez que le plug-in JellyBean se connecte au réseau (si il échoue, vérifiez les identifiants que vous avez renseignés)
  5. Renseignez l'adresse IP affichée sur l'écran du plug-in JellyBean dans l'application JellyBean
  6. La configuration est terminée
3. Une configuration existe déjà
Si une configuration existe déjà

Étapes du mode Standalone :

  1. Vérifiez que vous êtes bien connecté au réseau WiFi JellyBean_Hotspot

    2. SSID -> JellyBean_Hotspot

    WPA -> jellybean

  2. Ouvrez l'application JellyBean et appuyez sur le bouton 'Standalone'
  3. La configuration est terminée


Étapes du mode Serveur :

  1. Vérifez que vous êtes connecté au même réseau WiFi que le plug-in JellyBean
  2. Ouvrez l'application JellyBean, appuyez sur le bouton 'A setup already exists'
  3. Renseignez l'adresse IP affichée sur l'écran du plug-in JellyBean dans l'application JellyBean
  4. La configuration est terminée
4. Je veux changer de mode exceptionnellement

Vous pouvez changer le mode du plug-in JellyBean

  1. Ouvrez l'application JellyBean et allez dans les options (bouton 'Settings')
  2. Allez dans la section 'Network' et appuyez sur le bouton 'Change mode'
  3. Le plug-in JellyBean va changer de mode pour passer en mode Standalone
  4. N'oubliez pas de vous connecter au réseau WiFi JellyBean_Hotspot
Vous pouvez refaire cette manipulation pour repasser en mode Serveur
5. Mise à jour

Mise à jour de l'application JellyBean :

  1. Vérifiez dans le PlayStore


Mise à jour du plug-in JellyBean :

L'appplication JellyBean vous préviendra en cas de mise à jour disponible
  1. Il faut être connecté au même réseau WiFi que le plug-in JellyBean
  2. Téléchargez le dernier Firmware ici
  3. Ouvrez votre navigateur préféré et allez à l'adresse suivante : http://JellyBean_plug_IP/update
    4. ex: http://192.168.4.1/update
  4. Choisissez le fichier du dernier Firmware
  5. Appuyez sur le bouton 'Update' et attendez que le plug-in JellyBean redémarre
  6. La mise à jour est terminée

Comment l'utiliser ?

Une fois que l'application JellyBean et que le plug-in JellyBean app sont configurés, vous pouvez envoyer vos premères commandes

Rien n'est envoyé si le champ des commandes est vide
  • Le bouton "flèche vers le haut" enverra simplement les commandes
  • Le bouton "retour chariot" enverra les commandes avec un retour à la ligne à la fin de celles-ci

Dispositions clavier

Deux dispositions clavier sont disponibles dans les options de l'application JellyBean :

  • US_us (QWERTY)
  • FR_fr (AZERTY)

Le plug-in JellyBean a besoin de redémarrer pour appliquer les changements
