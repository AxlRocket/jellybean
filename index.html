JellyBean

A WiFi keyboard through an external plug-in

Download .apk Join the Discord

To use JellyBean app, you need to own a JellyBean plug-in

Modes

The JellyBean plug-in can run in 2 modes :

1. Standalone

You don't need to connect the plug-in to your WiFi network

Steps :

  1. Plug the JellyBean plug-in into your computer
  2. On your phone, connect to the JellyBean_Hotspot WiFi

    3. SSID -> JellyBean_Hotspot

    WPA -> jellybean

  3. Open the JellyBean app, press the 'Standalone mode' button
  4. You're ready to go, enjoy

2. Server

You'll need to configure it to connect it to your WiFi network

Steps :

  1. Plug the JellyBean plug-in into your computer
  2. On your phone, connect to the JellyBean_Hotspot WiFi

    3. SSID -> JellyBean_Hotspot

    WPA -> jellybean

  3. Open the JellyBean app, and enter your WiFi credentials
  4. Wait for the JellyBean plug-in to connect (if it fails, retry this step)
  5. Enter the IP adress showed on the JellyBean plug-in in the JellyBean app
  6. You're ready to go, enjoy

3. Existing configuration

If an existing configuration already exists

Standalone mode steps :

  1. Be sure to be connected to JellyBean_Hotspot

    2. SSID -> JellyBean_Hotspot

    WPA -> jellybean

  2. Open the JellyBean app, press the 'Standalone mode' button
  3. You're ready to go, enjoy

Server mode steps :

  1. Be sure to be connected to the same WiFi network as your JellyBean plug-in
  2. Open the JellyBean app, press the 'A setup already exists' button
  3. Enter the IP adress showed on the JellyBean plug-in in the JellyBean app
  4. You're ready to go, enjoy

Layouts

Two layouts are availables in the JellyBean app settings :

  • US_us (QWERTY)
  • FR_fr (AZERTY)

The JellyBean plug-in have to restart to take the changes
