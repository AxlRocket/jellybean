JellyBean

A WiFi keyboard through an external plug-in

Download .apk Join the Discord

To use JellyBean app, you need to own a JellyBean plug-in

How to configure it ?

1. Standalone
You don't need to connect the plug-in to your WiFi network

Steps :

  1. Plug the JellyBean plug-in into your computer
  2. On your phone, connect to the JellyBean_Hotspot WiFi

    3. SSID -> JellyBean_Hotspot

    WPA -> jellybean

  3. Open the JellyBean app, press the 'Standalone mode' button
  4. You're ready to go, enjoy
2. Server
You'll need to configure it to connect it to your WiFi network

Steps :

  1. Plug the JellyBean plug-in into your computer
  2. On your phone, connect to the JellyBean_Hotspot WiFi

    3. SSID -> JellyBean_Hotspot

    WPA -> jellybean

  3. Open the JellyBean app, and enter your WiFi credentials
  4. Wait for the JellyBean plug-in to connect (if it fails, retry this step)
  5. Enter the IP adress showed on the JellyBean plug-in in the JellyBean app
  6. You're ready to go, enjoy
3. Existing configuration
If an existing configuration already exists

Standalone mode steps :

  1. Be sure to be connected to JellyBean_Hotspot

    2. SSID -> JellyBean_Hotspot

    WPA -> jellybean

  2. Open the JellyBean app, press the 'Standalone mode' button
  3. You're ready to go, enjoy


Server mode steps :

  1. Be sure to be connected to the same WiFi network as your JellyBean plug-in
  2. Open the JellyBean app, press the 'A setup already exists' button
  3. Enter the IP adress showed on the JellyBean plug-in in the JellyBean app
  4. You're ready to go, enjoy
4. I want to switch mode exceptionally

You can switch the JellyBean plug-in mode

  1. Open the JellyBean app and go in the settings
  2. Go to the Network section and 'Change mode'
  3. The JellyBean plug-in will switch to Standalone mode
  4. Don't forget to connect your phone to the JellyBean_Hotspot
You can use the button to re-switch to server mode
5. Updates

JellyBean app updates :

  1. Check the PlayStore


JellyBean plug-in updates :

The JellyBean app will notify you if an update is available
  1. You have to be connected to the same network than JellyBean plug-in
  2. Download the latest firmware here
  3. Open your favorite webbrowser and go to : http://JellyBean_plug_IP/update
    4. ex: http://192.168.4.1/update
  4. Choose the firmware file
  5. Press "Update" button and wait for the JellyBean plug-in to reboot
  6. You're ready to go, enjoy

How to use it ?

Once the JellyBean app and JellyBean plug-in are setup you can send your first keystroke

Keystroke will not be send if empty
  • The button with the up arrow will send your keystrokes
  • The button with the carriage return arrow will send your keystrokes with a carriage return

Layouts

Two keyboards layouts are availables in the JellyBean app settings :

  • US_us (QWERTY)
  • FR_fr (AZERTY)

The JellyBean plug-in have to restart to take the changes


Custom keyboard

You can activate a custom keyboard in the JellyBean app settings

If you know what it's used for, use it ! Otherwise don't
A long press on the backspace button clear the "Your command" field
